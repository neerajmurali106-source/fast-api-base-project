# Fast API Base Project

A full-stack product management application built with **FastAPI**, **React**, **PostgreSQL**, and **SQLAlchemy**.

## 🚀 Features

- View all products
- Add new products
- Edit existing products
- Delete products
- Search products by ID, name, or description
- Sort products by ID, name, price, and quantity
- PostgreSQL database integration
- REST API using FastAPI
- React frontend
- CORS configuration for frontend-backend communication

## 🛠️ Technologies Used

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- psycopg2

### Frontend
- React
- Axios
- CSS
